# AI Resume Screening System — Week 1: Project Planning & Dataset Scoping

Virtual Data Science Apprentice — Python Specialist Intern (Week 1 of 4)

## Overview

This week's deliverable is the project proposal for the **AI Resume Screening System**, a Python-based data science project that will classify resumes into job categories and score how well a resume matches a given job description, using NLP and Machine Learning.

## Objective

Design a comprehensive project plan — objectives, scope, candidate public datasets, and methodology — that will guide the remaining three weeks of the internship (data cleaning, EDA, and model selection/evaluation).

## What's in This Report

- **Project objectives and goals** — primary, secondary, and learning objectives, plus the intended business value.
- **Scope** — what is and isn't covered in the 4-week engagement.
- **Candidate public datasets** — a labelled resume-text dataset (job category classification) and a supporting job-description dataset (for the matching component), with the rationale for choosing each.
- **High-level workflow** — data acquisition → cleaning → EDA → modeling → reporting.
- **Proposed methodology and tools** — Python libraries planned for each stage (pandas, scikit-learn, nltk/spaCy, matplotlib/seaborn).
- **Validation checkpoints** — one per week of the internship.
- **Anticipated challenges and mitigations** — class imbalance, inconsistent terminology, small dataset size, and fairness risk in automated screening.
